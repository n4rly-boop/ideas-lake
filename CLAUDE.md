## Код

- Идентификаторы и комментарии — английский, прочее — русский.
- Только stdlib + то, что уже стоит (`httpx`, `numpy`, `sentence-transformers`). Новую зависимость обосновать одной строкой. Уже обосновано: `neo4j` — Bolt-over-TLS из stdlib не адресуется.
- Промпты — текстовые файлы в `prompts/{step}/system.txt`, не строки в коде.
- **Fail-open запрещён**, и он редко выглядит как ошибка. Проверенные тихие пути: `finish_reason != "stop"`; строка длиной ровно `maxLength` (обрыв посреди слова с `finish_reason="stop"`); отсутствующий таймаут; пустой FTS-индекс; неявный AND в FTS5. Сбой арбитра → `pending_link`, не `add`, не пустая строка, не тихий пропуск.
- Structured output через `response_format.json_schema.schema` (вложенная форма, плоская молча игнорируется), `temperature=0` на извлечении, `enable_thinking=false` всегда. Схемы — литеральные плоские `dict`, без `$ref`. Не парсить JSON руками с ретраями.
- Формат B знает только `graph_client.py`. Всё остальное — через него. **Индекс тезисов — не формат B**, он мой: `index.py`.
- Нетривиальная логика оставляет проверку в `selfcheck.py` (assert, один запуск).

## Ревью

**Перед коммитом — несколько сабагентов на ревью, параллельно, разными взглядами.** Один агент проверяет одно и находит одно; три с разными задачами находят разное. Минимум:

- **fail-open** — статус, который врёт; пустой список вместо поломки; число, не сходящееся с тем, что отдаёт страница; захваченный и не отпущенный слот.
- **контракты** — модели ответа против строк хранилища, инварианты проекта (неизменяемость тезиса, изоляция формата B), OpenAPI против того, что ручка реально может вернуть.
- **атака на проверку** — мутационное тестирование `selfcheck`: внести по одному дефекту и посмотреть, ловит ли. Проверка, которая не падает на сломанном коде, хуже её отсутствия — она даёт ложную уверенность. Мутации гонять только `python3 -B` или с `rm -rf **/__pycache__`: Python инвалидирует `.pyc` по паре (mtime в секундах, размер), и мутация той же длины, записанная в ту же секунду, не выполняется вовсе — зеленеет старый байткод. Ложный CAUGHT хуже пропущенной мутации.
- Дыры в проверке обычно структурные, а не случайные: константа страницы больше фикстуры (весь многостраничный путь мёртв), одна сущность там, где инвариант про две (атрибуция неверифицируема), только happy-path (снятие любого стража зелёное). Ищи корень, а не список.

Ревьюеры читают, а не правят: возвращают находки с адресами, `git add/commit/push` не трогают. Писал код — не ревьюишь его сам. Находки триажить самому: агент ошибается, и его «баг» бывает верным поведением.
