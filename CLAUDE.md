## Документы

- Русский. Числа, имена полей, пути — как в источнике, без пересказа.
- Каждое утверждение с адресом: `[05] 05-repo-gigaevo-core.md:1151` или `file.py:39-64`. **Нет адреса — нет утверждения.** Не выдумывать числа и не сглаживать противоречия: расхождение источников — это находка, её пишем как есть.
- Меняешь факт в `01`–`08` — правь и строку в `README.md`/`00-overview.md`, если она стала неверной.

## Код

- Идентификаторы и комментарии — английский, прочее — русский.
- Только stdlib + то, что уже стоит. `httpx`/`numpy` — по необходимости, новую зависимость обосновать одной строкой.
- Промпты — текстовые файлы в `prompts/{step}/system.txt`, не строки в коде.
- **Fail-open запрещён.** Сбой LLM → в очередь `pending_link`, видимую в отчёте; не `add`, не пустая строка, не тихий пропуск. Ошибки не проглатывать.
- Structured output через function calling, `temperature=0` на извлечении. Не парсить JSON руками с ретраями.
- Формат B знает только `graph_client.py`. Всё остальное — через него.
- Нетривиальная логика оставляет проверку в `selfcheck.py` (assert, один запуск).
