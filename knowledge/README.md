| [`12-decisions-meetings.md`](./12-decisions-meetings.md) | **Решения встреч 29–30 июля. Главное: проект принимается по эксперименту**, а не по системе — четыре плеча абляции, контроль на шум, тест «та же задача второй раз с заполненным озером», 2 августа. Плюс: гипотеза как идея без доказательств, `trust_score` одним числом от LLM, синтез рандомом, «из веба в эволюцию — только через озеро», и что из этого ломает инварианты блока A. |
| [`13-run-ingest-and-graph-spec.md`](./13-run-ingest-and-graph-spec.md) | **Спека двух фич, реализована 2026-07-31:** приём логов эволюции (лог мутанта GigaEvo → тезисы формата `run`, конвертер вместо парсера сырья, линковка существующим арбитром) плюс `dirty` одним определением и `trust_score` судьёй-LLM с fail-closed на отказе — то, что перешло от B к A 2026-07-31. Там же переезд хранилища на локальный Neo4j без фолбэка на SQLite, гипотеза как идея с синтетическим листом (инвариант «идей без листьев ноль» заменён, а не снят) и что агентскому RAG нужно от блока A. **Рёбра остаются у B**, A их только читает. Замер по трём прогонам AIME (пересчитан 2026-07-31 после ревью): 308 программ, из них 182 с вычислимой дельтой и 647 правок; 111 строк с `fitness = -1000` — маркер отказа валидации, а не число, и первая редакция спеки сама на нём споткнулась. Код разошёлся со спекой в нескольких местах — судья работает не по двум триггерам, а сводом в конце фазы 2, вес доверия в ранжировании обнулён решением (не выполнен), проверки §10 п.26-34 не заведены — расхождения размечены в тексте блоками `[реализация 2026-07-31]`; на момент разметки `python3 -m lake.selfcheck --offline` был красным на 9 из 25 пунктов (`lake/README.md` §6). |
